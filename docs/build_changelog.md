# ビルドの変更記録

まとまった作業ごとに番号を 1 つ上げ、末尾に `- **ビルドN：タイトル**` を 1〜3 行で書く（何を・なぜ・どう変えたか。確かめたこと・確かめていないことを一言）。
番号は版の末尾の数字から続け（v2.1.78 ＝ ビルド78）、`src/dev.rs` の `BUILD` と合わせる（起動時のログに `build N` と出る）。使う人向けの変更は版ごとに `changelog.md` へ。

- **ビルド78：v2.1.78 の準備（固まる Preview の修正・タブの名前・数式・配色・更新ボタン・説明のタブ）**
  リストの中の 100% 幅の表で HelpView が固まるのを生成側で断った（Markdown 228 件で確認）。名前の無いタブは最初の行から名前を作る。数式を文字で簡易表示。
  既定の配色を元のダーク・ライトに戻した。更新ボタンは GitHub の最新の公開リリースと比べる。何も開いていない時は説明と操作のタブを出す（起動して確認）。タグでリリースへ自動で載せる CI。
  面積図のプレビュー（乗せる・押す）と、フォルダ・zip を開いた時に一度だけ欄を開く動き（起動して確認）。本文の見回りが面積図の小窓を消していたので、小窓の持ち主を分けた。
  ISO 9660＋Joliet＋Rock Ridge の読み取り（isofs.rs。ext と共通の image_kind・image_read・image_extract で一覧・検索・取り出し・面積図のプレビュー）。UDF 1.02〜2.60（メタデータ区画を含む）も udffs.rs で読み、UDF を持つ ISO は UDF を使う。Windows の IMAPI で作った UDF 1.02・2.50・ISO＋UDF をテストに同梱（testdata）。配布されている実物の ISO では未確認。
